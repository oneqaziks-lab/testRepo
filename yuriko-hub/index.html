О хабе

Yuriko Hub — это единая точка входа для всех проектов команды. Загрузочный терминал имитирует старт Linux-системы, а команда GUI открывает графическую часть хаба.

Как это работает

  • При входе автоматически выполняются 80 команд загрузки системы
  • После завершения загрузки становится доступна команда GUI
  • GUI — переключение в графический режим хаба
  • help — список доступных команд терминала
  • ai <вопрос> — спросить Yuriko AI прямо из терминала

Yuriko AI Assistant ✦

Встроенный умный ассистент: понимает вопросы на русском и английском, ищет ответы по базе знаний через BM25-индекс, решает математику собственным парсером выражений (скобки, степени, корни, проценты) и помнит контекст диалога. Работает полностью локально в браузере.

  • Открыть: кнопка ✦ AI Assistant, команда ai в терминале или Ctrl+J
  • Попробуй: «Что такое хаб?», «Сколько будет (12+8)*3 − sqrt(25)?», «15% от 2400», «пошути»
  • Slash-команды: /skills, /status, /clear

Экосистема: Rave + YkoTube + БД

Rave 💬 — мессенджер хаба: регистрация только через ботов-верификаторов с кодами доступа, двухфакторная аутентификация (6-значные коды от @Yuriko_AuthBot). YkoTube 📺 — видеохостинг: аккаунты не создаются отдельно — вход и регистрация выполняются через Rave (единый OAuth-подобный токен).

  • БД: две базы — yarikodb (Rave) и ykotube (YkoTube)
  • Подключение: root@localhost, пользователь root без пароля
  • Запуск сервера: node server/server.js → http://localhost:8080
  • Схема MySQL: sql/schema.sql · команды: rave, ykotube
