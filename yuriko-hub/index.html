О системе

Yuriko Hub — локальный графический хаб: карта домашней сети (реальные устройства из ARP), мессенджер Rave с 2FA-ботами, видеохостинг YkoTube со входом через Rave и встроенный AI-ассистент. Работает поверх XAMPP: Apache раздаёт страницы (порты 80/443), Node-сервер — API и БД (root@localhost, порт 8080).

Автообновление с GitHub: update.bat (Windows) или update.sh (Linux/macOS/cron).
