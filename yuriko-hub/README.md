# Yuriko Hub

Сайт-хаб между проектами команды **Yuriko**. При входе открывается терминал,
имитирующий загрузку Linux: автоматически выполняются **80 команд** инициализации
системы. После загрузки пользователь может ввести команду **`GUI`**, чтобы открыть
графическую часть хаба — витрину будущих проектов.

## Структура

```
yuriko-hub/
├── index.html            — разметка (экран терминала + экран GUI)
├── css/
│   └── style.css         — стили терминала и графической части
└── js/
    ├── boot-commands.js  — те самые 80 команд загрузки
    ├── terminal.js       — автозапуск команд + обработка ввода пользователя
    ├── projects.js       — каталог проектов (легко дополнять)
    └── gui.js            — переключение терминал ⇄ GUI, навигация по разделам
```

## Как запустить

Просто откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
cd yuriko-hub
python3 -m http.server 8090
# затем откройте http://localhost:8090
```

## Команды терминала

| Команда    | Действие                                        |
|------------|-------------------------------------------------|
| `GUI`      | открыть графическую часть хаба                  |
| `help`     | список доступных команд                          |
| `status`   | состояние сервисов хаба                          |
| `projects` | список проектов текстом                          |
| `banner`   | показать ASCII-логотип                           |
| `clear`    | очистить экран                                 |
| `reboot`   | перезапустить загрузку (снова 80 команд)         |
| `whoami`   | немного ролевой игры ✦                           |

Поддерживается история команд (стрелки ↑ / ↓).

## Как добавить проект

Откройте `js/projects.js` и допишите объект в массив `PROJECTS`:

```js
{
  icon: "🎨",
  name: "Moy Project",
  desc: "Краткое описание проекта.",
  status: "soon",        // "soon" | "progress" | "ready"
  url: "#",              // ссылка на проект, когда появится
}
```

Карточка появится в GUI автоматически. Статус `soon` добавляет ленту «СКОРО».

## Возврат в терминал

Из GUI можно вернуться в терминал кнопкой **`</> Terminal`** (или `Ctrl+``),
после чего снова доступна команда `GUI`.
