# Yuriko Hub 🏡🌸

**Сервер умного дома** с графическим интерфейсом: 16 устройств в 6 комнатах,
сцены одним нажатием, живая статистика и **Yuriko AI Assistant**, который умеет
управлять домом голосовыми (текстовыми) командами. Внутри хаба также живут
проекты: мессенджер **Rave** (боты с кодами + 2FA) и видеохостинг **YkoTube**
(вход через Rave). Всё работает локально через XAMPP + Node.js.

> Терминал с Linux-boot-секвенцией убран из интерфейса (v4.0) — хаб открывается
> сразу в графической части. Файлы `js/terminal.js` и `js/boot-commands.js`
> остались в репозитории, но страницей не подключаются.

## ⚡ Быстрый старт (Windows + XAMPP) — 3 шага

### Шаг 1. Установите Node.js (один раз)

Команда `node` не найдена, потому что Node.js не установлен — XAMPP его
не поставляет и не умеет запускать. Скачайте LTS с https://nodejs.org/
и при установке **оставьте включённой галочку «Add to PATH»**.
После установки перезапустите cmd и проверьте:

```cmd
node -v        ← должно вывести v20.x / v22.x
```

### Шаг 2. Запустите сервер хаба

Два способа — выберите любой:

* **Двойной клик по файлу `start-server.bat`** в папке `yuriko-hub` — самый простой способ;
* либо вручную в консоли:

```cmd
cd V:\xampp\htdocs\yuriko-hub
node server/server.js
```

Сервер поднимется на **http://localhost:8080** и сам раздаст все страницы
хаба и API. Оставьте это окно открытым — сервер должен работать, пока вы
пользуетесь хабом.

> ❗ **Никогда не открывайте `server.js` двойным кликом!**
> Windows запустит его через Windows Script Host (JScript), который не
> понимает синтаксис Node.js — отсюда ошибка *«Синтаксическая ошибка,
> Код: 800A03EA»*. Файл `.js` — это код для Node, а не для WSH.
> Правильный вход: `start-server.bat` или команда `node server/server.js`.

### Шаг 3. Откройте хаб

Рекомендуемый адрес (страницы раздаёт Node-сервер):

👉 **http://localhost:8080** — хаб сразу открывается в графическом интерфейсе
умного дома (без терминала и ожидания загрузки).

Можно и через Apache/XAMPP (**http://localhost/yuriko-hub/**, порты 80/443) —
страницы откроются, а API они найдут сами на :8080 (автоопределение в
`js/config.js`). Но вариант из шага 2 проще и без сюрпризов.

## 🖥 Что внутри хаба (GUI)

### Боковая панель
Логотип ⌂ Yuriko Hub, навигация: **Обзор / Устройства / Сцены / Проекты / О системе**,
живые часы, приветствие по времени суток и индикатор статуса шлюза — он тестирует
`/api/health`: зелёный «Шлюз онлайн · БД подключена», жёлтый «офлайн — UI работает
автономно». Кнопка **✦ AI Assistant** в шапке (или горячая клавиша **Ctrl+J**).

### 💡 Умный дом (`js/home.js`)
* **16 устройств в 6 комнатах**: свет, телевизор, кондиционер, колонка, чайник,
  кофемашина, холодильник, ночник, шторы, увлажнитель, тёплый пол, замок,
  камера, робот-пылесос и др.
* Управление: тумблеры вкл/выкл, ползунки яркости / громкости / открытия штор /
  целевых °C, выбор крепости кофе.
* **Обзор**: температура, влажность, число активных устройств, потребление в Вт
  (всё считается из реальных состояний), быстрые действия, избранные устройства.
* **6 сцен одним нажатием**: Доброе утро, Режим «Кино», Уютный вечер,
  Спокойной ночи, Я ушёл из дома, Добро пожаловать домой.
* Фильтр по комнатам, тосты-уведомления. Состояние дома сохраняется в
  localStorage и переживает перезагрузку страницы.

### 🤖 Yuriko AI Assistant (`js/ai-engine.js`, `js/ai-ui.js`)
Локальный ассистент без внешних API — «думает» на месте:
* **Управление умным домом**: «включи свет на кухне», «выключи телевизор»,
  «сделай яркость люстры 40», «убавь громкость колонки до 20»,
  «поставь кондиционер на 24 градуса», «режим кино», «спокойной ночи»,
  «открой замок», «сколько устройств включено?» (со списком активных).
* **База знаний BM25** по проекту (статьи «Умный дом», «Сцены», «Проекты»…) —
  ранжированный поиск вместо простого contains.
* **Математика**: собственный парсер выражений — скобки, степени, проценты,
  sqrt/sin/cos/log, словесные формы («плюс», «умножить на»).
* **Память контекста диалога**: «прибавь 10», «умножь на 2», «расскажи про него».

### 📱 Проекты (раздел «Проекты»)
| Проект | Статус | Как открыть |
|---|---|---|
| **Rave** — мессенджер (аналог Telegram) | готов | `/rave.html` или чистый URL `/rave` |
| **YkoTube** — видеохостинг (аналог YouTube) | готов | `/ykotube.html` или чистый URL `/ykotube` |
| **Orbit Notes** — заметки/вики | в разработке | карточка проекта |

* **Rave**: боты с кодами подтверждения — @Yuriko_VerifyBot (код регистрации),
  @Yuriko_AuthBot (двухфакторка, одноразовые коды SHA-256, TTL 5 мин),
  @Yuriko_SupportBot.
* **YkoTube**: регистрация только через Rave (OAuth-подобная схема); токены
  входа лежат в общем localStorage origin'а — залогинились в одном месте,
  вход действует на всех страницах.

## 🔌 Порты

| Сервис | Порт | Комментарий |
|---|---|---|
| Apache (XAMPP) | **80 / 443** | раздача страниц (необязательно) |
| MySQL (XAMPP) | **3306** | `root` без пароля |
| Node API хаба | **8080** | статика + `/api/*`; порт меняется переменной окружения `PORT` |

Конфликтов между ними нет: Apache и Node работают одновременно.

## 🗄 База данных

Локальная БД реализована в `server/db.js` (JSON-таблицы в `server/data/`,
подключение `root@localhost` без пароля, базы **yarikodb** и **ykotube**).
`server/data/` исключён из git — ваши аккаунты и сообщения не затираются
при обновлениях.

Для «настоящего» MySQL в XAMPP приложен готовый скрипт схемы:

```cmd
V:\xampp\mysql\bin\mysql.exe -u root < sql\schema.sql
```

## 🔄 Автообновление с GitHub

* **`update.bat`** (Windows/XAMPP) — first-run привязывает `origin`, делает
  fetch, сравнивает коммиты, `stash → reset --hard origin/main → stash pop`
  (локальные данные БД сохраняются) и перезапускает Node-сервер.
* **`update.sh`** (Linux/macOS/WSL) — то же самое + строка для cron каждые
  15 минут.

В обоих файлах достаточно указать `REPO_URL` на свой репозиторий:
https://github.com/oneqaziks-lab/testRepo

## 🧰 Частые проблемы

| Симптом | Причина и решение |
|---|---|
| «node не распознана» | Node.js не установлен или не добавлен в PATH — см. Шаг 1 |
| Ошибка WSH «Код: 800A03EA» | Вы дважды кликнули `server.js` — запускайте через `start-server.bat` |
| «⚠ Сервер хаба не отвечает» | Не запущен Node-сервер (Шаг 2). Проверка: http://localhost:8080/api/health |
| Порт 8080 занят | `set PORT=8090 && node server/server.js` (config.js найдёт API автоматически) |
| Хаб открывается, но статус «офлайн» | UI работает автономно (localStorage); для БД-функций Rave/YkoTube нужен сервер |

## 📁 Структура проекта

```
yuriko-hub/
├── index.html            — GUI умного дома (главная страница хаба)
├── rave.html             — отдельная страница мессенджера Rave
├── ykotube.html          — отдельная страница видеохостинга YkoTube
├── start-server.bat      — запуск сервера двойным кликом
├── update.bat / .sh      — автообновление с GitHub
├── .htaccess             — чистые URL (/rave, /ykotube) + защита server/data
├── css/style.css         — тёмная неоновая тема
├── js/
│   ├── config.js         — автоопределение адреса API (Apache/Node)
│   ├── gui.js            — оболочка интерфейса (навигация, статус шлюза)
│   ├── home.js           — умный дом: устройства, комнаты, сцены, статистика
│   ├── ai-engine.js      — мозг ассистента (BM25, математика, управление домом)
│   ├── ai-ui.js          — чат-виджет ассистента
│   ├── projects.js       — каталог проектов
│   ├── apps.js           — общая логика Rave/YkoTube
│   └── standalone.js     — работа приложений без Node-сервера
├── server/
│   ├── server.js         — Node-сервер: статика + REST API (:8080)
│   ├── db.js             — локальная БД (root@localhost, yarikodb + ykotube)
│   └── data/             — JSON-таблицы (в git не попадает)
└── sql/schema.sql        — схема для MySQL (XAMPP)
```
